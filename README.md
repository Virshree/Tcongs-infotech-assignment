# 🚀 Tcongs Infotech Website

A modern, responsive corporate website built using **React.js**, **Vite**, **Tailwind CSS**, and **Framer Motion**. The website showcases Tcongs Infotech's digital services, development process, company information, and contact section with a clean UI/UX.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Virshree/Tcongs-infotech-assignment.git
```

Move into the project folder

```bash
cd tcongs-infotech
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
